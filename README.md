# ✨ Refugio CasaCuento

Sitio web de **Refugio CasaCuento** — hotel boutique y hostal mágico en Mantagua, Concón, V Región de Chile.

🌐 **Sitio en vivo:** [https://refugiocasacuento.vercel.app](https://refugiocasacuento.vercel.app)

## 🎭 Concepto

Tercera versión del sitio que combina:
- La estética mágica e inmersiva de [CasaCuentoMagic](https://casacuentomagic.vercel.app)
- El flujo de reserva funcional de [CasaCuento](https://casacuento.vercel.app)
